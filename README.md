# Daily News Website

A daily news website that provides news updates across various categories. This project demonstrates expertise in front-end development and UI design.

---

## Features
- Fetches real-time news data using the News API.
- Categorized news for easy browsing.
- Responsive design with a modern and user-friendly interface.

---

## Technologies Used
- **Frontend:** React, HTML, CSS, JavaScript, Bootstrap
- **API:** News API (for fetching categorized news)

## Getting Started

### Prerequisites:
- Node.js and npm installed on your system.
- API Key from [News API](https://newsapi.org/).

### Steps to Run:
1. Clone the repository:
   ```bash
   git clone https://github.com/Viveknakka/news-app
   cd news-app
2. npm install
3. npm start
